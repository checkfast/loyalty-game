# Loyalty Game · WY Group

Sito vetrina del programma fedeltà per ristoratori: Web App raccolta punti, gadget personalizzati e Button Challenge.

## Struttura

```
index.html                     pagina unica (HTML, CSS e JS inclusi)
assets/button-challenge.jpg    foto demo Button Challenge
.nojekyll                      pubblica i file così come sono su GitHub Pages
```

## Pubblicazione su GitHub Pages

1. Crea un nuovo repository su GitHub (es. `loyalty-game`)
2. Carica tutti i file di questa cartella nella radice del repository (Add file → Upload files)
3. Vai su Settings → Pages
4. In "Build and deployment" scegli Source: **Deploy from a branch**, Branch: **main**, cartella **/ (root)**, poi Save
5. Dopo 1-2 minuti il sito è online su `https://TUO-UTENTE.github.io/loyalty-game/`

## Dominio personalizzato (opzionale)

In Settings → Pages → Custom domain inserisci il dominio, poi dal tuo provider DNS crea un record CNAME verso `TUO-UTENTE.github.io`

## Da personalizzare

Email, telefono, indirizzo e dati aziendali sono nella sezione `#contatti` e nel footer di `index.html`
